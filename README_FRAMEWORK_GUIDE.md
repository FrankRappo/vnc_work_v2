## КОГДА ИСПОЛЬЗОВАТЬ КАКУЮ

### Windows-копия — для:
- Чтения кода/документации фреймворка
- CDP-управления Edge (edge_cdp.py — нативный Windows)
- Изучения fixtures/evidence (кадры, эталоны)
- PowerShell-обходов (Телеграм через Invoke-RestMethod)

### WSL-копия — для:
- Подключения к машинам (RustDesk/AnyDesk/SSH)
- Кликов и ввода текста (x99.sh, clip_paste)
- Скринов экранов (x99.sh shot)
- Работы с GUI через Xvfb (:99, :103)
- SSH-туннелей ко всем машинам

## ГРАБЛИ (кратко — полный список в GATE.md §е, 46 пунктов):
1. Кириллица через x99.sh type НЕ доставляется — только clip_paste
2. Перед вводом всегда клик в поле → скрин → проверить фокус
3. RustDesk-кадры могут быть заморожены — проверять diff
4. viewport vs native координаты ±120px
5. WSL-пайп флапает → ретраи 30-60с, -d Ubuntu-24.04
6. Системные службы НЕ убивать (sshd, туннели, планировщики)
7. Каждый скрин смотреть глазами — никогда по памяти
