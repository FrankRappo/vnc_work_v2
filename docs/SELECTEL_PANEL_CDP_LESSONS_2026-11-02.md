# Грабли Selectel-панели через CDP (час боевых ошибок 02.11.2026) — чеклист на будущее

Контекст: создание сервисного API-пользователя vpc.admin в панели my.selectel.ru через
CDP к живому Edge владельца (порт 9222, профиль владельца). Час потрачен на борьбу с
дропдауном роли. Всё ниже — проверено на реальных кликах, не теория.

## 🔴 Проверить ДО любой UI-автоматизации

1. **`document.visibilityState` и `hasFocus()` — первая проверка.** Если окно свёрнуто
   (`hidden`) — dropdown-оверлеи не открываются/мгновенно закрываются, клики «в пустоту»,
   и никакие повторы не помогут. Просить владельца развернуть окно, ждать `visible`,
   и только потом автоматизировать. (Мы час кликали при `hidden`.)
2. **Не убивать браузер владельца ради CDP-порта** (taskkill + перезапуск убил живую
   2FA-сессию — владелец проходил вход заново). Подключаться только к уже запущенному
   инстансу или просить владельца запустить с флагом.
3. **Сбросить артефакты прошлых сессий**: `body.style.zoom`, Emulation.setDeviceMetricsOverride,
   остаются после скриншотов/экспериментов и сдвигают ВСЕ координаты (клики молча мазали).
   Перед стартом: `document.body.style.zoom=''`, снять Emulation.

## 🔴 Дропдауны ant-design (nz-select / tree-select)

4. **Ищи дропдаун по всему документу**: `[...document.querySelectorAll('[class*=ant-select-dropdown]')].find(d=>d.offsetParent!==null)`
   — он НЕ всегда внутри `.cdk-overlay-container` (зависит от версии CDK/рендера). Поиск
   только внутри overlay-container = вечный «NO_DD» при открытом дропдауне.
5. **«Не найдено» в дереве = данные не загрузились или застрял поиск.** Не лечится
   повторными кликами: закрыть (Escape), переоткрыть — при открытии уходит новый запрос.
   Проверяй маркер загрузки (например, первый элемент списка «billing»).
6. **Клик по родительскому узлу продукта (vpc с шевроном) = только РАСКРЫТЬ.** Роли —
   ДЕТИ (vpc.admin, vpc.viewer...). Один клик по родителю роль не выбирает.
7. **Кликабельный элемент — весь treenode**, не текстовый ребёнок: `el.closest('.ant-select-tree-treenode')`,
   центр его ректа. Клик по маленькому span с текстом может не регистрироваться.
8. **Виртуальный список перерисовывается**: координаты, замеренные до клика, устаревают
   за доли секунды. Замер и клик — атомарно в одном CDP-соединении (или повторный замер
   непосредственно перед кликом).
9. **Input.dispatchMouseEvent mouseWheel НЕ возвращает ответ** — `cdp.call()` с ожиданием
   ответа таймаутит. Отправлять fire-and-forget (ws.send без ожидания), потом отдельно
   проверять состояние.

## 🔴 Координаты и viewport

10. **Viewport (innerHeight=836) — граница кликов.** Элемент на y=1000 кликабелен
    в DOM, но клик по координате y>innerHeight уходит в никуда. Элементы ниже фолда:
    поднять `body.style.zoom` (0.8) по приёму фреймворка, проскроллить ВНУТРЕННИЙ контейнер
    дропдауна, или расширить viewport через `Emulation.setDeviceMetricsOverride`.
11. **Скриншоты CDP в 1.5× (Windows DPI)**: координаты с такого скрина = viewport×1.5.
    НЕ смешивать: либо скрин 1:1 (Page.captureScreenshot своего соединения при deviceScaleFactor 1),
    либо делить на масштаб. Лучше — координаты из `getBoundingClientRect` (всегда viewport).
12. **Страница скроллится между действиями**: замер → скролл страницы фреймворком → клик
    по старой координате = клик по соседнему полю (мы кликали в «Группу» вместо «Роль»).
    Порядок: scrollIntoView → замер → клик БЕЗ промежуточных скроллов.

## 🟢 Рабочий рецепт (итог)

1. `visibilityState==='visible'` + `hasFocus()` — проверить.
2. Открыть дропдаун: `mouseMoved` → `mousePressed` → `mouseReleased` (framework click) по
   центру селектора (rect из DOM).
3. Проверить загрузку данных в дропдауне (маркер-элемент); «Не найдено» → Escape → переоткрыть.
4. Найти узел: `innerText.trim()==='vpc'` (точное совпадение), взять treenode-предка.
5. Навести мышь на узел, СКРИН — убедиться, что курсор на строке (подсветка).
6. Крутить колесо (fire-and-forget) на позиции узла — узел поднимается в видимую зону.
7. Клик по узлу — раскроется; перечитать детей; клик по дочерней роли.
8. Проверить: поле роли показывает выбранное; скрин; только потом «Сохранить/Создать».

## Пример успешного кода (фрагмент)

- Атомарный замер+клик: `cdp/selectel_atomic.py`, финальная версия `cdp/selectel_wheel_flow.py`
